# Prerequisites
Need `node.js` and `websocket-client` python library
# Usage
1. node server.js
2. on client run `python client.py`
3. open the `basic_webpage.html`
4. Use start and stop buttons to trigger the start and stop commands. 

You should see `"Laptop starting collection"` and `"Laptop stopping collection"` messages being printed to the screen when the button is being pressed.
